Mural da Turma: Guia do Aluno

Este é o Guia do Aluno. Quando um comentário nos arquivos style.css e script.js disser "veja o PASSO no Guia do Aluno", é este documento.

O que vamos fazer

Vamos construir um mural de recados, como aqueles quadros de aviso da escola.

A pessoa escreve o nome, escolhe o humor do dia e escreve um recado. Ao clicar em Publicar recado, o recado aparece na tela dentro de um cartão colorido. Cada cartão tem um botão Remover.

Você não vai começar do zero. A página já está quase pronta. Falta você fazer duas coisas:

  1. Arrumar a aparência (deixar tudo no lugar certo).
  2. Fazer a página funcionar (o que acontece quando clicamos nos botões).

Este guia não entrega o código pronto. Ele diz o que você precisa fazer, em qual aula e em qual arquivo está a resposta e dá uma pista. Tudo o que você precisa já foi visto nas aulas dos dias 03 e 04, que estão no repositório do curso. O código você encontra, entende e escreve.

Faça com calma, um passo de cada vez. Errar faz parte de aprender.

Antes de começar

1. Baixe as aulas e o projeto. Você já sabe fazer isso, é só para reforçar.

  1. Aperte a tecla Windows, digite cmd e aperte Enter. Abre a tela preta do prompt.
  2. Entre na pasta Documentos digitando cd documents e apertando Enter.
  3. Baixe o repositório digitando o comando abaixo e apertando Enter:
git clone https://github.com/09117498-ctrl/Projetos-alunos-2026

Se você já tem a pasta Projetos-alunos-2026 no computador, não precisa baixar de novo. Só atualize: digite cd Projetos-alunos-2026 e depois git pull.

2. Abra a pasta no VS Code. No VS Code, clique em Arquivo e depois em Abrir Pasta. Entre em Documentos e escolha a pasta Projetos-alunos-2026.

No painel da esquerda você vai ver as pastas Dia01, Dia02, Dia03, Dia04 e a pasta mural-da-turma. O seu trabalho é na pasta mural-da-turma.

3. Abra a página no navegador. Dentro da pasta mural-da-turma, clique com o botão direito no arquivo index.html e escolha Open with Live Server. Se não aparecer essa opção, abra a pasta pelo Explorador de Arquivos do Windows e dê dois cliques no arquivo index.html.

4. Conheça os 3 arquivos da pasta mural-da-turma.

Arquivo Para que serve Pense nele como...
index.html Os textos, campos e botões da página O esqueleto (já está pronto, não mexa)
style.css As cores, o tamanho e a posição das coisas A roupa (você vai completar)
script.js O que acontece quando alguém clica O cérebro (você vai completar)

5. Regra de ouro: sempre que mudar algo, faça isto.

  1. Aperte Ctrl + S no VS Code (isso salva o arquivo).
  2. Vá ao navegador e aperte F5 (isso atualiza a página).
  3. Veja se deu certo.

Se você esquecer de salvar, nada muda na página. Quando o arquivo tem uma bolinha branca na aba, é porque ainda não foi salvo.

Como procurar a resposta

Você não precisa pesquisar na internet. Todas as respostas estão nas aulas, dentro da pasta do repositório. Em cada passo, o guia diz o arquivo e o trecho onde olhar. Use estas ideias:

  1. Os arquivos de código das aulas (style.css do Dia 03 e Script.js do Dia 04) têm comentários com títulos em letras maiúsculas, como CARD FLEXÍVEL. Abra o arquivo no VS Code e procure o título que o guia indicar.
  2. As HQs das aulas são os arquivos .html. Para ler uma, abra a pasta pelo Explorador de Arquivos e dê dois cliques no arquivo. Ela abre no navegador. Dentro dela, use Ctrl + F para buscar uma palavra.
  3. Buscar em todos os arquivos de uma vez: no VS Code, aperte Ctrl + Shift + F, digite a palavra da pista (por exemplo, justify-content) e veja em quais arquivos ela aparece.
  4. Leia a pista com atenção. Ela traz as palavras-chave que você vai procurar.
  5. Não copie às cegas. Ao achar um exemplo, troque os nomes pelos nomes deste projeto.
  6. Tentou por uns 10 minutos e travou? Pergunte a um colega ou chame o professor. Ele pode dar uma pista extra.

Dica: digite o código em vez de colar. Cuidado com maiúsculas, minúsculas e com os sinais { }, ( ), ; e '. Uma letra diferente já faz o código parar de funcionar.

Parte A: a aparência (arquivo style.css)

Abra o arquivo style.css da pasta mural-da-turma. Dentro dele há 5 comentários escritos PASSO 1, PASSO 2 e assim por diante. É ali que você vai trabalhar. (Um comentário é um texto que o computador ignora. Ele serve só para nos orientar.)

Em cada passo: apague o comentário e escreva o CSS no lugar.

Passo 1: título e botão na mesma linha

O que queremos: no topo (header), o título de um lado e o botão "Alternar tema" do outro, na mesma linha.

Onde procurar: - CSS do Dia 03, no trecho CARD FLEXÍVEL. A ideia é a mesma: uma coisa de um lado e outra do outro. - HQ do Flexbox, Capítulo 3 "O drama do card" e a "Folha de cola da Dona Flex" (justify-content e align-items).

Pista: você vai usar três propriedades: uma para ligar o Flexbox, uma para distribuir o espaço entre os itens e uma para alinhar os itens no meio, na vertical. Para "um em cada ponta", procure o valor que empurra o espaço entre os itens.

Como saber que deu certo: o título "Mural da Turma" fica à esquerda e o botão "Alternar tema" fica à direita.

Passo 2: os dois campos lado a lado

O que queremos: os campos "Seu nome" e "Seu humor hoje" ficam um ao lado do outro. Eles estão dentro de um bloco chamado .form-linha.

Onde procurar: - CSS do Dia 03, no trecho FORMULÁRIO COM FLEXBOX. - HQ do Flexbox, Capítulo 2 "Pai, filhos e os dois eixos" e a "Folha de cola" (gap).

Pista: duas propriedades: a que liga o Flexbox e a que cria um espaço entre os itens. Use 12px de espaço.

Como saber que deu certo: os dois campos aparecem lado a lado.

Passo 3: os recados um embaixo do outro

O que queremos: quando os recados aparecerem, eles ficam em uma pilha, um embaixo do outro, no bloco .mural.

Onde procurar: - CSS do Dia 03, no trecho 4. LISTA E CARDS DE TAREFAS. - HQ do Flexbox, Capítulo 2 e a "Folha de cola" (flex-direction).

Pista: três propriedades: ligar o Flexbox, mudar a direção para coluna e criar um espaço de 12px entre os itens.

Como saber que deu certo: por enquanto nada muda. Você vai ver a pilha quando houver recados na tela, na Parte B.

Passo 4: o cartão do recado

O que queremos: dentro do .card, o texto fica de um lado e o botão "Remover" do outro, centralizados na vertical.

Onde procurar: é parecido com o Passo 1! Releia o seu próprio código do Passo 1 e o trecho CARD FLEXÍVEL do CSS do Dia 03.

Pista: as mesmas três propriedades do Passo 1, mais um espaço de 12px entre os itens.

Como saber que deu certo: também só aparece quando houver cartões.

Passo 5: funcionar no celular

O que queremos: em telas pequenas (até 600 pixels de largura), o título e o botão do topo ficam um embaixo do outro, e os campos do formulário também.

Onde procurar: - CSS do Dia 03, no trecho 5. RESPONSIVIDADE (MEDIA QUERIES - CELULAR). - HQ do Flexbox, Capítulo 5 "Quando a tela encolhe" e Capítulo 6 "A Guarda da Tela".

Pista: escreva a regra que vale só para telas de até 600px de largura (max-width). Dentro dela, mude a direção do header e do .form-linha para coluna. Se sobrar um espaço estranho entre os campos, tire o gap do .form-linha dentro dessa regra. Escreva no final do arquivo.

Como saber que deu certo: diminua a largura da janela do navegador. Quando ficar bem estreita, o layout vira uma coluna.

Parte B: o funcionamento (arquivo script.js)

Abra o arquivo script.js da pasta mural-da-turma. Ele tem 8 comentários PASSO 1 a PASSO 8. Escreva o código logo abaixo de cada comentário, sem apagar o resto do arquivo.

Palavras que vão aparecer:

  • Elemento: cada pedaço da página, como um botão, um campo ou um título.
  • Evento: algo que a pessoa faz na página, como clicar.
  • Constante (const): uma "caixinha com etiqueta" onde guardamos algo para usar depois.

Atenção aos nomes. Um passo usa o que o passo anterior criou. Por isso, use exatamente estes nomes de constantes (à direita está o id do elemento no index.html):

Nome da constante id no HTML
form form-recado
inputNome nome
selectHumor humor
textoMensagem mensagem
mural mural
contador contador
btnLimpar btn-limpar
btnTema btn-tema

Os passos 2 a 6 ficam dentro de um bloco que já existe no arquivo: aquele que começa com form.addEventListener('submit', function (event) { e termina com });. Escreva no lugar dos comentários, entre essas duas linhas.

Passo 1: apresentar os elementos ao JavaScript

O que queremos: o JavaScript ainda não sabe quem é quem na página. Vamos "procurar" cada elemento pelo seu id e guardar em uma constante, usando os nomes da tabela acima.

Onde procurar: - Script do Dia 04, no trecho 1. SELEÇÃO DOS ELEMENTOS DO HTML. - HQ do DOM, Capítulo 3 "A Árvore DOM".

Pista: são 8 linhas parecidas, uma para cada linha da tabela.

Como saber que deu certo: salve, atualize e aperte F12 no navegador, depois clique em Console. Não pode haver mensagens em vermelho.

Passo 2: o que acontece quando clica em "Publicar recado"

O que queremos: três coisas, nesta ordem: - (a) a página não pode recarregar; - (b) guardar o que a pessoa escreveu (nome, recado e humor), sem espaços sobrando no começo e no fim dos textos; - (c) se o nome ou o recado estiver vazio, mostrar um aviso e parar.

Onde procurar: - Script do Dia 04, no trecho 2. ESCUTAR O EVENTO DE SUBMIT DO FORMULÁRIO. Ele faz exatamente essas três coisas. - HQ do DOM, Capítulo 4 "Ouvindo o clique" e Capítulo 5 "A fábrica de cards" (passos 1 e 2).

Pista: procure por "impedir o comportamento padrão", por "pegar o valor de um campo" (.value) e por "tirar espaços" (trim). Para o aviso, use alert. Para parar a função, use return. Aqui você tem dois textos para checar: use o sinal que significa "ou" (||).

Como saber que deu certo: salve, atualize, deixe tudo vazio e clique em Publicar recado. Deve aparecer um aviso e a página não deve recarregar.

Passo 3: criar o cartão

O que queremos: criar um elemento do tipo article (o cartão) e guardar em uma constante chamada card. Depois, dar a ele duas classes: card e humor- seguida do humor escolhido (por exemplo, humor-feliz).

Onde procurar: - Script do Dia 04, no trecho 3. CRIAR O NOVO CARD DE TAREFA DINAMICAMENTE (para criar o elemento). - HQ da Árvore, Parte 5, "Ação 3 · Ligar e desligar classes" (para as classes).

Pista: para juntar dois textos em um só, use o sinal +. O humor está guardado na constante que você criou no Passo 2. Na Ação 3, procure o comando que adiciona uma classe.

Como saber que deu certo: ainda não aparece nada. O cartão existe só na memória.

Passo 4: escrever dentro do cartão

O que queremos: criar uma caixa (div) com a classe info e três elementos dentro dela: - um h3 com o nome (constante titulo); - um p com o recado (constante texto); - um small com o texto "Humor: " e o humor escolhido (constante detalhe).

Onde procurar: - HQ da Árvore, Parte 5, "Ação 7 · Criar e remover itens": ela cria um elemento, escreve o texto nele e coloca dentro de outro. - HQ do DOM, Capítulo 5 "A fábrica de cards" e Laboratório 5 "textContent ou innerHTML?".

Pista: crie cada elemento, escreva o texto com textContent e depois coloque os três dentro da div com appendChild.

Como saber que deu certo: ainda não aparece nada. Falta o Passo 6.

Passo 5: o botão "Remover"

O que queremos: criar um botão (constante btnRemover) do tipo button, com o texto "Remover" e a classe btn-remover. Quando alguém clicar nele, o cartão some e o número ao lado de "Recados" é atualizado.

Onde procurar: - HQ da Árvore, Parte 5, "Ação 7 · Criar e remover itens": o código dela cria um botão, escuta o clique e remove o item. É quase o mesmo! - HQ da Árvore, "Ação 4 · Mudar atributos" (para o type). - HQ da Árvore, "Ação 1 · Trocar o texto" (para escrever um número na página). - Para contar os cartões do mural: procure children nos cartões de vocabulário da Parte 1 da HQ da Árvore e length na "Ação 6 · Reagir ao que a pessoa digita".

Pista: dentro da função do clique, apague o card. Depois, escreva em contador quantos filhos o mural tem agora. Os cartões ficam dentro do mural, ou seja, são "filhos" dele.

Como saber que deu certo: ainda não aparece nada. Falta o Passo 6.

Passo 6: colocar o cartão na página

O que queremos: agora o cartão aparece de verdade. Faça cinco coisas: - coloque a info e o btnRemover dentro do card; - coloque o card dentro do mural; - atualize o número em contador, do mesmo jeito do Passo 5; - limpe os campos do formulário; - leve o cursor de volta para o campo do nome.

Onde procurar: Script do Dia 04, nos trechos 4. ADICIONAR O NOVO CARD DENTRO DA LISTA e 5. LIMPAR OS CAMPOS DO FORMULÁRIO E DAR FOCO NO INPUT.

Pista: appendChild, a linha do contador que você escreveu no Passo 5, reset() no formulário e focus() no campo do nome.

Como saber que deu certo: salve, atualize, escreva um nome e um recado e clique em Publicar recado. Um cartão colorido deve aparecer e o número em "Recados" deve subir. Teste o botão Remover. Teste também os outros humores e veja a cor da borda mudar.

Passo 7: o botão "Limpar mural"

O que queremos: ao clicar em "Limpar mural", todos os recados somem e a contagem volta para 0. Esse código fica fora do bloco do submit.

Onde procurar: HQ da Árvore, Parte 4 "Oficina de código", Desafio 4 · Limpar a lista (abra a Dica e a Solução) e a "Folha de cola da árvore", cartão "Remover".

Pista: escrever um texto vazio ('') no conteúdo do mural apaga tudo o que está dentro dele. Depois, atualize o contador do mesmo jeito dos passos anteriores.

Como saber que deu certo: publique alguns recados e clique em "Limpar mural".

Passo 8: o botão "Alternar tema"

O que queremos: ao clicar em "Alternar tema", a página troca entre claro e escuro. O CSS já sabe pintar tudo de escuro quando o body tem a classe escuro.

Onde procurar: HQ da Árvore, Parte 5, "Ação 3 · Ligar e desligar classes".

Pista: nessa ação, procure o comando que funciona como um interruptor: liga a classe se ela não existe e desliga se ela existe. O elemento é o body da página (document.body) e a classe se chama escuro.

Como saber que deu certo: clique no botão: a página escurece. Clique de novo: ela volta ao normal.

Terminou? Confira

  • ☐ Clicar em "Publicar recado" não recarrega a página.
  • ☐ Com nome ou recado vazio aparece um aviso e nenhum cartão é criado.
  • ☐ Depois de publicar, os campos ficam vazios.
  • ☐ O número ao lado de "Recados" sobe, desce e zera conforme os cartões.
  • ☐ A cor da borda muda de acordo com o humor.
  • ☐ "Remover" apaga só aquele cartão.
  • ☐ "Limpar mural" apaga todos.
  • ☐ "Alternar tema" troca entre claro e escuro.
  • ☐ Em janela estreita, o layout fica em coluna.

Não funcionou? Tente isto

  1. Você salvou? (Ctrl + S) E atualizou a página? (F5)
  2. Aperte F12 no navegador e clique em Console. Se houver uma mensagem em vermelho, leia o nome do arquivo e o número da linha. Ela diz onde está o problema.
  3. Compare com o Script.js do Dia 04, letra por letra. Maiúsculas, minúsculas, aspas ' ', chaves { } e parênteses ( ) fazem diferença.
  4. Volte um passo. Se você acabou de escrever algo e parou de funcionar, o erro quase sempre está nesse último pedaço.
  5. Chame o professor e mostre a mensagem vermelha. Isso ajuda muito.

Desafios extras (só se sobrar tempo)

  1. Mostre no cartão a hora em que o recado foi publicado. No VS Code, aperte Ctrl + Shift + F e busque por toLocaleTimeString: a HQ do DOM usa isso.
  2. Mostre quantos caracteres o recado já tem enquanto a pessoa digita (por exemplo, 12/100). Veja a HQ da Árvore, Parte 5, "Ação 6 · Reagir ao que a pessoa digita".

Como entregar

Quando terminar, envie seu trabalho como o professor combinou, usando os comandos que você já conhece. No terminal do VS Code (menu Terminal > Novo Terminal), digite um de cada vez, apertando Enter depois de cada linha:

git add .
git commit -m "Projeto Mural da Turma"
git push
  • git add . separa os arquivos que você mudou.
  • git commit -m "..." salva uma versão, com um nome.
  • git push envia para o GitHub.
